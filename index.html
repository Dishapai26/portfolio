ClinicPulse

A dashboard that shows how many patients each hospital department sees, and how long they wait, so a manager can spot busy days at a glance.

  1. Load the data. An Angular service fetches visit records as JSON from a REST API.
  2. Filter it. Pick a department and a date range. RxJS streams recompute everything from those two choices.
  3. Show it. Summary tiles come first, then a daily trend line and a department comparison.

PromptLens

A small tool that scores an AI prompt while you type and tells you what is missing. Written as a patent-style idea: a method for real-time scoring of a prompt against a fixed clarity rubric.

  1. Read the prompt. As you type, the text is checked against five simple rules.
  2. Score it. Context, task, limits, output format and example or audience are worth 20 points each.
  3. Coach it. Every missing item shows one plain tip, so the prompt improves before it is sent to an LLM API.
